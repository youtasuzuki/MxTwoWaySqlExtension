# Description
- This is an add-on for Mendix Studio Pro (v11.12 or later) designed for development using the TwoWaySQL, SaferOQL and jXLSer modules. It allows you to open SQL/OQL/XLSX files in an external editor directly from the Microflow editor in Studio Pro with a single action (Ctrl+Shift+L).  
- The add-on automatically launches the application associated with the ".sql", ".oql" and ".xlsx" file extensions on your Windows system and opens the corresponding file.
# Usage
- If there is only one TwoWaySQL or SaferOQL or jXLSer Java action in the Microflow you are currently viewing, you can open the associated file by simply pressing Ctrl+Shift+L.
- If there are multiple TwoWaySQL or SaferOQL or jXLSer Java actions in the Microflow, you will need to select the specific one you wish to open.
